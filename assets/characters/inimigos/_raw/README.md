# diabrete — arte original (fonte)

PNGs como saíram do SpriteForge AI, **antes** da limpeza de resíduo de chroma key.

Guardados como fonte, no mesmo espírito de `assets/characters/frames/`.
O `.gdignore` impede a Godot de importar estas cópias: o jogo carrega apenas os
sheets limpos em `assets/characters/inimigos/`.

Nada aqui foi criado, redesenhado ou "melhorado" por IA. A limpeza aplicada aos
sheets do jogo está descrita em `docs/ASSET_WORKFLOW.md`, seção
"Limpeza de resíduo de chroma key".
