# Regra para conteúdo novo

Nenhuma arma nova entra apenas porque é "legal".

Ela deve preencher um comportamento diferente, por exemplo:
- alvo próximo;
- cone;
- linha;
- AoE;
- orbital;
- chão;
- ricochete;
- summon;
- aura;
- cadeia.

Evitar cinco armas com o mesmo comportamento mudando somente sprite.
